How to connect

  1. Open your hosting provider's private Environment settings.
  2. Add the provider API key as a secret environment variable.
  3. Set the model and endpoint variables as needed.
  4. Redeploy/restart the service and refresh this page.

No login is required by this starter. Because the dashboard is public, do not add an endpoint that lets visitors change secret keys or server settings.
